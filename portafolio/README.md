## Descripción del Proyecto
Este proyecto consiste en un portfolio personal desarrollado con React y Vite como primer Trabajo Práctico de la materia Programacion 4. La aplicación implementa el uso de componentes reutilizables, paso de información mediante props, renderizado dinámico de datos mediante .map(), manejo de estados interactivos con `useState` y la utilizacion de useEffect.

## Instalación de Dependencias

Para instalar las dependencias necesarias del proyecto, seguir los siguientes pasos:

- Clonar el repositorio:
git clone URL_DEL_REPOSITORIO en este caso la URL es: https://github.com/Joacoavila9/tp1-react-portfolio-joaquin-avila-lahr.git


- Ingresar a la carpeta del proyecto: 
cd portafolioReact


- Instalar las dependencias:
npm install

Este comando instala todas las dependencias necesarias especificadas en el archivo package.json.

- Ejecutar el proyecto en modo desarrollo:
npm run dev

- Abrir en el navegador la dirección indicada por Vite, normalmente:

http://localhost:5173

## Requisitos previos
